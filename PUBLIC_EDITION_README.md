# Freedom Travel OS — Public Edition 0.1

This is a separate public foundation created from the Korea Edition UI. It uses new local-storage keys and contains no preloaded Korea trip information.

## Included
- First-trip onboarding
- User-created trip profile
- Editable outbound and return flights
- Editable hotel
- Packing, Budget, Explore, Booking History and Memories
- Local backup/import
- GitHub Pages base path: `/FreedomTravelOS-Public/`
