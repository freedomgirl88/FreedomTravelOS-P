# Freedom Travel OS P — v0.2.0

This is the separate general-use edition of Freedom Travel OS. It contains no preloaded personal Korea trip data and is designed for users to create and manage their own trips.

## Identity
- App name: Freedom Travel OS P
- Repository: `FreedomTravelOS-P`
- GitHub Pages base: `/FreedomTravelOS-P/`
- Suggested URL: `https://freedomgirl88.github.io/FreedomTravelOS-P/`
- Storage namespace: `ftos-p-*`
- PWA cache namespace: `ftos-p-*`

## v0.2 foundation
- Unique PWA identity so it can coexist with the Korea Edition on iPhone.
- Multiple trips with separate flight, hotel, budget, packing, itinerary, booking and memory data.
- Create, switch and delete trips from Settings.
- P-only backup/import format.
- Functional Explore day and place planning.

Connect this folder only to `freedomgirl88/FreedomTravelOS-P`.


## Reinstall after v0.2.1
Delete the old FTOS P Home Screen icon, clear site data for freedomgirl88.github.io in the browser, open the P URL again, then add it to the Home Screen.
