# Freedom Travel OS P v0.2.0

- Renamed the general-use app to Freedom Travel OS P / FTOS P.
- Added a unique manifest ID, scope, start URL and service-worker cache namespace.
- Corrected every GitHub Pages and service-worker path to `/FreedomTravelOS-P/`.
- Prevented the P Edition service worker from deleting Korea Edition caches.
- Added multiple-trip support with fully separate data per trip.
- Added create, switch and delete trip controls in Settings.
- Restricted backups to FTOS P data only.
- Preserved the working splash screen, onboarding, Explore editor and existing functional modules.
